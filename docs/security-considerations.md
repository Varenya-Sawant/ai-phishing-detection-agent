# Security & Ethical Considerations

## Privacy
- Only relevant email data is processed
- No unnecessary data retention

## Limitations
- LLMs may produce false positives/negatives
- Edge cases may be misclassified

## Overreliance Risk
- System should assist, not replace human judgment

## Accountability
- Workflow design and prompt engineering define system behavior

## Future Risk Mitigation

- Add threat intelligence APIs
- Implement feedback loop
- Improve explainability
